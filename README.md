# Tesrael (תצוגה מקדימה)

אתר חנות קונספט לחלקי חילוף ואביזרים לרכבי טסלה.

## מה כולל האתר
- קטלוג מוצרים עם קטגוריות וסינון לפי דגמים (Model S / 3 / X / Y / Cybertruck, כולל Highland/Juniper)
- הצגת מחיר לכל מוצר ולכל סוג/וריאציה
- ממשק עגלה (הוספה/הסרה/שינוי כמות) עם סיכום ביניים
- כפתור תשלום המציג הודעת "בקרוב" (ללא רכישה אמיתית)
- חלון פרטי מוצר במסך מלא עם דירוגים ותיאורים לפריט ולכל סוג (חומר/צבע/צורה)
- בחירה והצגה של וריאציות שונות לכל מוצר לפי דגם

## הרצה / תצוגה מקדימה
זהו אתר סטטי. פתחו את `index.html` ישירות בדפדפן, או הריצו שרת מקומי מתוך התיקייה:

```powershell
python -m http.server 8000
```

לאחר מכן גלשו לכתובת `http://localhost:8000`.

## הערות
- **שם:** שם החנות הוא "Tesrael".
- **רכישה:** הזמנה מקוונת מושבתת כרגע בכוונה; הממשק מיועד לתצוגה מקדימה בלבד.
- **שפה וכיוון:** האתר מוצג בעברית ובכיווניות מימין לשמאל (RTL).
- **תמונות:** תמונות המוצרים נטענות מתוצאות חיפוש תמונות ברשת לפי מוצר ודגם.
- **סימנים מסחריים:** Tesla ושמות הדגמים הם סימנים מסחריים של Tesla, Inc. ומשמשים לציון התאמה בלבד.
